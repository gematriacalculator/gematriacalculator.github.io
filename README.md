# Gematria Calculator

A static GitHub Pages website for calculating English, Simple, Jewish, reverse, reduction, name, and Hebrew gematria values.

The site includes browser-based calculators, number meaning guides, educational gematria articles, and policy pages for public launch.

## Local Preview

Serve the folder with any static server, then open the local URL:

```powershell
python -m http.server 8123
```

## Publish Target

This repository is intended for GitHub Pages at:

https://gematriacalculator.github.io/

## Notes

- Calculator input is processed in the browser.
- `sitemap.xml` contains the indexable English pages.
- Localized pages are currently marked `noindex, follow` until full translations are ready.
- Add the real AdSense `ads.txt` publisher line only after Google provides it.
