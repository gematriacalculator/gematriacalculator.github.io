What Is English Gematria?

On this site, English gematria means the Latin-letter system where values move in steps of 6: A=6, B=12, C=18, and the pattern continues through Z=156. It is different from Simple gematria, where A=1 through Z=26.

The calculation itself is straightforward. Write the word or phrase, look up the value for each supported letter, and add the numbers. Uppercase and lowercase letters are treated the same, so Light, LIGHT, and light use the same letter values.

How to Calculate English Gematria

Choose English Gematria, enter a word or phrase, and add the six-step values for each letter. Unsupported characters such as punctuation, emojis, and extra spaces are ignored. The calculator displays the same process in the result card, so you can audit the total letter by letter.

For example, LIGHT is counted as L=72, I=54, G=42, H=48, and T=120. Those values add up to 336.

Simple vs English vs Jewish Gematria

Simple Gematria follows the normal alphabet order from 1 to 26. English Gematria multiplies those positions by 6. Jewish Gematria uses a different Latin-letter scale where some letters, including J, U, V, W, X, Y, and Z, have much larger values. Select the method that matches the comparison you want to make.

English Gematria Calculator FAQ

What is English gematria?

It is the Latin-letter system where A equals 6, B equals 12, and the pattern continues in six-step values through Z as 156.

Can I use phrases?

Yes. Spaces and punctuation are ignored, while supported English letters are counted.

Why do some words share the same value?

Different letter combinations can add to the same total, which is one reason people compare words symbolically.

Is English gematria exact science?

No. It is an interpretive symbolic practice, not a scientific measurement or prediction tool.

Reading English Gematria Results

English gematria results are easiest to read when you keep the full spelling beside the total. A short word may produce the same value as a longer word, but the breakdown will show that the two totals came from different letter patterns. This is why the calculator displays each counted letter instead of only showing a final number.

When comparing two English values, use the same capitalization, spelling, and method. Capital letters do not change the total, but alternate spellings, initials, hyphens, and abbreviations can. If you are studying a phrase, calculate the full phrase first, then calculate key words separately to see where the value is coming from.

Responsible Calculator Use

Gematria works best when the calculator supports your thinking rather than replacing it. Use the result as a way to notice patterns, compare spellings, or organize symbolic notes. If a number feels meaningful, slow down and check the breakdown before drawing conclusions. The letters, language, method, and context all matter.

For study notes, record the exact text, the selected method, and the date of the calculation. This makes your comparisons easier to repeat and keeps the interpretation clear. Avoid using any gematria value as advice about money, health, law, religion, relationships, or major life decisions.
